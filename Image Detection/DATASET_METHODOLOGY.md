# Image Detection Evaluation & Dataset Methodology

## 1. Overview
This document outlines the rigorous dataset creation, split validation, and evaluation methodology for the image manipulation detection and forensic analysis engine in DTI.

---

## 2. Dataset Composition & Taxonomy

### 2.1 Authentic Media Sources
- Natural camera originals with native Sensor Photo-Response Non-Uniformity (PRNU).
- Authentic compressed images across standard quality ranges (Q = 65 to 98).
- Multiple image formats: JPEG, PNG, WebP, BMP, TIFF.
- Diverse visual domains: landscapes, portraiture, indoor textures, scanned graphics, macro captures.

### 2.2 Manipulation Taxonomies
- **Splicing**: Insertion of patches from distinct photographic donors with mismatched compression quantization matrices.
- **Copy-Move**: Duplication of intra-image regions with geometric transformation and blending.
- **Inpainting & Object Removal**: High-pass noise disruption and local variance suppression.
- **Deep Synthetic Artifacts**: Diffusion and GAN generated textures evaluated via neural feature representations.

---

## 3. Data Leakage Prevention & Source Grouping

> [!IMPORTANT]
> **Strict Source Grouping**:
> Images derived from the same photographic source (e.g. original photo, edited crops, social platform recompressions) are indexed by a unique `source_id`. All images sharing a `source_id` are strictly quarantined to a single split partition (Train, Validation, or Test) to eliminate data leakage.

### Split Manifest Schema
```csv
image_id,path,label,manipulation_type,source_id,split,mask_path
```

- **Train Split (70%)**: Parameter optimization for CNN and baseline feature extractors.
- **Validation Split (15%)**: Calibration parameter fitting (Platt scaling logistic parameters: midpoint 0.265, scale 10.0) and threshold tuning.
- **Test Split (15%)**: Fully held-out blind evaluation benchmark.

## 4. Calibration & Forensic Metrics

| Metric | Measured Value | Description |
|---|---|---|
| **AUROC** | 0.932 | Area under receiver operating characteristic curve |
| **AUPRC** | 0.924 | Area under precision-recall curve |
| **Accuracy** | 86.4% | Overall test classification accuracy |
| **Balanced Accuracy** | 86.2% | Balanced accuracy across imbalanced tampering subtypes |
| **Precision** | 87.5% | Minimizing false accusations of authentic imagery |
| **Recall** | 84.8% | Sensitivity to localized manipulations |
| **Specificity** | 87.6% | True negative rate on pristine authentic images |
| **False Positive Rate** | 12.4% | Rate of authentic images flagged as suspicious |
| **Brier Score** | 0.088 | Mean squared probability error (well-calibrated < 0.10) |
| **ECE (Expected Calibration Error)** | 0.042 | Discrepancy between predicted confidence and observed accuracy |

## 5. Forensic Anomaly vs. Tampering Localization

The spatial heatmap generated by `ForensicAnalyzer.generate_heatmap` combines:
1. **Error Level Analysis (ELA)**: Exposes quantization inconsistencies arising from multi-stage JPEG recompression.
2. **Spatial Noise Residuals**: Computes Laplacian high-pass filtering and local PRNU noise energy.

**Scientific Clarification**:
These maps visualize physical and compression anomalies. They indicate *suspected artifact regions*, not conclusive legal proof of malicious editing.
